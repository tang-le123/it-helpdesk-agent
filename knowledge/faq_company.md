# 星澜科技 IT 环境概览

> 适用范围：全体员工 · 维护：IT 服务台 · 版本 v3.1 · 更新 2026-10

## 公司概况
星澜科技是一家 800 人的 SaaS 公司，总部在上海张江，另设北京、深圳、成都三个分部。主营企业协同与数据产品，客户以中大型制造与零售企业为主。

## 办公系统
- 即时通讯与审批：飞书
- 企业邮箱：飞书邮箱，域名 @xinglan.tech
- CRM：销售易；ERP：金蝶云星空；代码托管：GitLab；项目管理：Jira
- 单点登录：飞书 SSO，全系统强制 MFA

## 设备与网络
- Windows 占 70%（ThinkPad T14、Dell Latitude），macOS 占 30%（MacBook Pro 14）
- 设备统一由 Intune 管理，资产编号形如 AST10001
- 办公网段 10.10.0.0/16；Wi-Fi：Xinglan-Staff / Xinglan-Guest
- 远程接入：GlobalProtect，地址 vpn.xinglan.tech

## 服务与时效
- 报障入口：飞书工作台 → IT 服务 → 提交工单；热线 8000
- 服务时间：工作日 9:00–19:00；19:00–22:00 仅处理 P1
- P1 30 分钟响应 / 4 小时解决；P2 4 小时响应 / 1 个工作日；P3 1 个工作日响应 / 3 个工作日
- 工单编号形如 TKT10001，资产编号形如 AST10001

## 审批与红线
- 审批链：直属主管 → 部门负责人 → IT 管理员 → 信息安全组（高风险）
- 数据分级 L1 公开 / L2 内部 / L3 客户数据 / L4 核心密钥；L3 及以上禁止导出到个人设备
- 禁止私接路由器、禁止使用未审批的 AI 工具、移动存储必须加密
