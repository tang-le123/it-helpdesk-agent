# License 申请与回收

> 适用范围：全体员工 · 责任人：IT-应用支持组 · 版本 v2.0

## 两类 License
- 浮动 License：按并发使用，如 MATLAB、Adobe Creative Cloud，用完即释放
- 固定 License：绑定账号，如 Figma、JetBrains 全家桶，需按人分配

## 申请流程
1. 飞书 → IT 服务 → License 申请
2. 选择软件与类型，说明使用周期
3. 直属主管审批；单价超过 5000 元/年的加签部门负责人
4. IT 分配并登记，浮动 License 直接开通，固定 License 1 个工作日内

## 使用规则
- 固定 License 仅限本人使用，禁止转借
- 连续 60 天未使用的固定 License 会被回收
- 项目结束或离职时自动回收

## 常见问题
- 提示“License 已达上限”：浮动 License 需等待释放，固定 License 提 P3 申请扩容
- 换电脑后 License 失效：重新登录即可，绑定的是账号不是设备
- 能否申请两个版本：同一软件只分配一个版本

## 季度盘点
IT 每季度盘点一次 License 使用率，闲置超过 60 天的回收并通知本人。
