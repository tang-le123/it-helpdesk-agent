# 数据分级与导出

> 适用范围：全体员工 · 责任人：信息安全组 · 版本 v2.5

## 四级分类
- L1 公开：官网文案、公开白皮书，可自由使用
- L2 内部：制度、周报、非敏感代码，限公司内部
- L3 客户数据：客户名单、合同、工单内容，需授权
- L4 核心密钥：数据库口令、API Key、私有密钥，严格管控

## 各级别要求
- L2：可存飞书文档，禁止发到外部群
- L3：必须加密存储，导出需审批，带水印与审计
- L4：仅限信息安全组与系统 owner，禁止导出到任何终端

## 导出流程
1. 飞书 → IT 服务 → 数据导出
2. 填写数据范围、用途、接收方、保存期限
3. 直属主管 + 数据 owner 审批；L3 加签信息安全组
4. 导出文件加密，7 天内删除，IT 抽查

## 常见问题
- 能否用个人网盘传客户名单：禁止，属于严重违规
- 能否把数据发给 AI 工具：按《AI 工具使用规范》，L3 一律禁止
- 离职时数据怎么处理：交接给主管，个人设备上的副本必须删除并确认

## 违规处理
- 首次：书面警告并参加安全培训
- 造成泄露：按信息安全事件处理，可能解除劳动合同并追究法律责任
