# 软件白名单与自助安装

> 适用范围：全体员工 · 责任人：IT-应用支持组 · 版本 v3.0

## 白名单（示例）
- 办公：飞书、Microsoft 365、Chrome、Edge、7-Zip、Zoom
- 研发：VS Code、Git、Docker Desktop、Postman、DBeaver、JetBrains Toolbox
- 设计：Figma、Adobe Creative Cloud（浮动 License）
- 安全：1Password、CrowdStrike Falcon

## 自助安装
1. 打开“公司门户”（Intune）或飞书 → IT 服务 → 软件中心
2. 选择软件，点击安装
3. Windows 需重启的会提示；macOS 需在“隐私与安全性”里允许

## 版本策略
- 默认安装稳定版，不追 beta / nightly
- 安全补丁 7 天内强制更新，员工不得关闭自动更新
- 大版本升级由 IT 灰度发布，先 5% 用户再全量

## 不在白名单
走《软件安装申请》，需主管审批；付费软件另走《License 申请与回收》。

## 常见问题
- 门户里找不到软件：说明未授权，提申请
- 安装被拦截：杀毒软件或权限不足，提 P3 工单
- 能否装 Steam / 游戏：禁止，与工作无关
