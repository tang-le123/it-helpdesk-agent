# 设备以旧换新与升级

> 适用范围：全体员工 · 责任人：IT-桌面支持组 · 版本 v2.0

## 换新周期
- 标准周期：设备满 4 年可申请换新
- 提前换新：电池健康度低于 80%，或维修次数一年内超过 3 次
- 不满足条件的，需部门负责人特批

## 申请条件
- 现设备无重大人为损坏，否则先按报修流程处理
- 已完成数据备份（OneDrive 或飞书文档）
- 名下无逾期未归还的备用机或外设

## 流程
1. 飞书 → IT 服务 → 设备换新
2. 填写现设备资产编号与换新理由
3. 直属主管审批 → IT 评估 → 库存匹配
4. 新机到位后 3 个工作日内归还旧机

## 旧机处理
- IT 统一做数据擦除（符合 NIST 800-88），再决定复用或报废
- 员工不得自行拆机取硬盘
- 涉及 L3 数据的设备，擦除需信息安全组见证

## 常见问题
- 想升级高配：需部门负责人审批，且原设备需满 2 年
- 换新期间没电脑用：可申请备用机
- 旧机还能用，能否留给部门：不行，统一回收入库
