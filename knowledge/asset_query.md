# 资产查询与归属

> 适用范围：全体员工 · 责任人：IT-桌面支持组 · 版本 v2.2

## 查询入口
飞书工作台 → IT 服务 → 我的资产，可查看本人名下全部设备。

## 可查信息
- 资产编号（AST1xxxx）、设备类型、型号
- 序列号、领用时间、存放地点
- 保修到期日（到期前 30 天飞书提醒）
- 当前状态：在用 / 维修中 / 库存 / 已退役 / 丢失

## 归属规则
- 设备归属以资产系统登记为准，不以实际使用人为准
- 转岗不转移设备，跨城市调动需走设备调拨
- 离职时设备随离职流程归还，未归还会从最后一个月工资中扣除

## 常见问题
- 查不到名下设备：可能登记在部门公共资产下，提 P3 工单核对
- 保修到期：IT 统一续保，员工无需操作
- 想换新机：见《设备以旧换新与升级》，不是所有岗位都符合条件

## 盘点
- 每年 3 月、9 月各盘点一次，员工需在飞书确认名下资产
- 逾期未确认的，账号权限可能被临时限制
