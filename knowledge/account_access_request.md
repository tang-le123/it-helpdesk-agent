# 业务系统权限申请（CRM / ERP / GitLab）

> 适用范围：全体员工 · 责任人：IT-账号权限组 · 版本 v2.6

## 原则
最小权限、按岗授权、到期回收。权限跟着岗位走，不跟着人走；转岗时旧权限先回收再开通新权限。

## 申请流程
1. 飞书 → 审批 → IT 服务 → 权限申请
2. 选择系统与权限包（如 CRM-客户导出、ERP-采购审批、GitLab-Maintainer）
3. 直属主管审批 → 系统 owner 审批 → IT 执行
4. 高危权限（客户导出、财务付款、生产库）加签信息安全组

## 时效
- 普通权限：1 个工作日内开通
- 高危权限：2 个工作日内，需说明用途与期限
- 默认有效期 90 天，到期自动回收，可申请续期

## 常见问题
- 审批卡住：飞书审批里可催办，超过 2 个工作日找 IT 升级
- 权限不够用：不要借同事账号，重新提申请
- 离职或转岗：权限随流程自动回收，无需单独申请
- 临时项目：可申请 30 天短期权限，到期不续

## 红线
- 禁止共享账号，禁止转授权限
- 客户数据导出仅限 L3 授权人员，且必须走审计日志
- 生产库写权限一律双人复核
