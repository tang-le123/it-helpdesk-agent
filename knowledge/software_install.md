# 软件安装申请

> 适用范围：全体员工 · 责任人：IT-应用支持组 · 版本 v3.1

## 先看白名单
飞书工作台 → IT 服务 → 软件中心，可直接自助安装白名单内的软件，无需审批。

## 白名单外软件
1. 飞书 → IT 服务 → 软件安装
2. 填写软件名称、版本、用途、是否含 License
3. 直属主管审批
4. 涉及付费或安全敏感的，加签 IT 管理员 / 信息安全组
5. 审批通过后由 IT 推送安装，通常 1 个工作日

## 安全要求
- 只允许官方安装包，禁止破解版、绿色版、来路不明的激活工具
- 需要管理员权限的安装由 IT 远程执行，员工不共享本机管理员密码
- 涉及数据处理的软件需通过安全评估（如爬虫、抓包、远控工具）

## 常见问题
- 装完打不开：检查是否被杀毒软件拦截，提 P3 工单
- 需要旧版本：说明兼容性原因，IT 提供指定版本
- 个人软件能否装：与工作无关的一律不装
- 试用期软件：可申请 30 天试用 License，到期卸载

## SLA
- 白名单：自助即时
- 白名单外：1 个工作日
- 需安全评估：3 个工作日
