# 外网代理与域名白名单

> 适用范围：研发、数据、设计岗 · 责任人：IT-网络组 · 版本 v1.9

## 默认策略
办公网默认直连互联网，国内站点无需代理。访问境外技术站点（GitHub、PyPI、Docker Hub 等）走公司代理，保证稳定与审计。

## 代理配置
- 地址：proxy.xinglan.tech，端口 8080
- 认证：工号 + SSO 密码
- 系统代理由 Intune 自动下发，浏览器无需手动设置

## 域名白名单
- 默认已放行常用研发站点
- 新域名需申请：飞书 → IT 服务 → 网络白名单
- 填写域名、用途、预计使用时长
- 审批人：部门负责人 + 信息安全组
- 处理时效：1 个工作日

## 常见问题
- pip / npm 下载慢：确认已走代理，或改用国内镜像
- 代理后部分国内站点打不开：在代理客户端里配置直连规则
- 需要长期访问某境外服务：走年度白名单评审，不要反复申请

## 红线
- 禁止使用未经审批的翻墙工具
- 禁止把代理账号共享给外部人员
- 代理日志留存 180 天，用于安全审计
